# 模型回合运行器

M5.1 已把本机 Ollama 的单次发言请求接入原有圆桌状态机。它不需要先扩充到 12 人；可以使用既有历史公共人物的显式草稿预览。当前只加载发言者的人物规范、锚点、样例和圆桌适配层，其余人物只通过已提交发言出现。

## 本机试用

先按[本地状态工具](11-本地状态工具.md)创建并 start 会话，安装并启动本机模型后运行（模型名替换为实际安装名称）：

```powershell
python 圆桌会议/scripts/roundtable_runner.py --session RT-20261007-900 --model <本机模型名> --confirm-local-service
```

每执行一次只生成下一位的一个回合。可传 --speaker 指定已在会话中的人物。默认服务是本机回环地址，明确拒绝远程或云模型。身份预检失败不分配票据；没有自动重试或模型下载。

已有 pause、resume、interject、finish 命令继续生效。生成时不占用状态锁，暂停/插话后迟到结果不会提交。这里只实现票据拒收，没有承诺中断底层 HTTP 请求或停止模型计算。模型错误、格式错误或校验失败会在票据仍有效时暂停会话，保留全部此前回合；用户检查后显式 resume，再决定是否重新请求。

模型只能输出自然正文及回应、主张等内容字段。身份、主张编号、时间和结构检查说明由程序填写；不接受模型自行写入批准字段或调用工具。accepted 仍只表示结构和状态协议通过，semantic_quality_verified=false，不是人工质量验收。

## 当前范围与下一步

M5.2a 已加入当前发言者的证据卡检索：按议题、当前问题、上一回合和待回应插话做词项重合排序，最多六张、20 KiB；无命中可为空，不声称穷尽或语义检索。仅 reviewed 且非 local_only 的卡片可进入上下文。模型可选填 evidence_ids，必须来自实际加载集合；来源编号由程序从卡片回链，撤回/文件变更仍由原状态机拒绝。引用不表示结论已经成立，basis 保留 simulation，引用卡片时另标 inference，不伪造人物原话或已核实事实。现代事实不足时应请求事实核查并暂停。上下文超出容量明确拒绝，不静默截断。

## 结束并成稿

会话达到回合上限或显式 finish 后进入 finishing，再运行：

```powershell
python 圆桌会议/scripts/roundtable_editor.py --session RT-20261007-900 --model <本机模型名> --confirm-local-service
```

成稿器只接收已提交回合和议题/目标，不读取更多人物知识。一次本机模型请求生成发展脉络、共识、分歧和未决问题；程序填写身份、模拟声明、背景和待审说明。每段引用现有回合；共识至少引用两个发言者，分歧列出的人物必须有对应回合。这些是结构检查，无法代替人工核查归纳是否忠实。

成功后 current.json 指向的不可变快照同时包含 transcript.md、essay.md、article.json 和 provenance.md，附录按段落回链回合及其依据。失败不改变已提交讨论，不自动重试；修复本机条件后可再次执行。独立编辑锁防止重复请求，版本核验防止迟到稿覆盖新状态。崩溃留下 .editor-generation.lock 时，先确认没有编辑进程，再手动清理该会话锁文件；不会自动抢占。
