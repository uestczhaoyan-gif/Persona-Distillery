## 必检项

- [ ] 人物身份无歧义，没有混入同名者或第三方言论。
- [ ] 来源台账完整，重要主张有精确定位。
- [ ] 转载与重复内容没有被当成独立证据。
- [ ] 人物卡写出了盲区、思想变化和争议，而非单一英雄叙事。
- [ ] 对话规范不会伪造原话、私人记忆或当代表态。
- [ ] 保留测试没有用于合成人物提示词，评测结果达到目标等级。
- [ ] 上传资料的授权、第三方信息、远程处理和分享范围均已核验。
- [ ] 发布包不含原始私密文件、密钥、绝对路径或未脱敏内容。
- [ ] 头像符合视觉规范，并明确是风格化人物图。
- [ ] 撤回和更正路径可用。
