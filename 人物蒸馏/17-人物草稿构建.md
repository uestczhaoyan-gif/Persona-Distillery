# 人物草稿构建

## M3.5a 审阅文档

`render_spec.render_views(verified_review, catalog, display_name)` 是纯本地渲染器。调用方必须先经 `read_spec_review` 和 `read_merge` 核验当前规范审核与资料；渲染器再次检查已采纳规范及其证据绑定。拒绝的规范、伪造完成标记或过期目录不能渲染。

输出 11 份 Markdown 视图：档案、人物卡、证据、对话规范、核心锚点、原创示例、评测待办、空会话记录、构建报告、情境记忆和使用样例待办。模型与人工文本作为字面内容处理，转义 HTML、图片与链接语法，避免审阅文档主动加载外部资源。证据编号与出处保留在审阅层；运行时不要求日常回答逐句展示编号。

锚点是可选择倾向，语言与节奏随交流需要调整；材料不足不补写人格套路。原创示例明确不是原话、真实会话或独立测试。文档中的评测与头像继续标为未完成，不把一个 Markdown 文件集合当成完整人物。

此节点不写磁盘、不创建 manifest、不启用人物能力、不发布。后续外部草稿写入器将绑定当前规范审核和资料版本；实际新增完成的人物仍必须具备 AI 头像、真实试聊与相应质量验收。
