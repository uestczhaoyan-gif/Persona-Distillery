# 本地文档解析

## M3.6a HTML 解析核心

`local_html.extract_html(payload)` 接收最多 5 MiB 的 UTF-8（可有 BOM）字节，返回纯文本。块元素和表格单元保留换行，字符实体解码；忽略 head、script、style、template、noscript、iframe、object、SVG、MathML、注释及显式 hidden/aria-hidden 子树。不下载 URL、图片、样式，不执行脚本或浏览器渲染。

这不是浏览器可见文本重现：不计算 CSS，不执行动态网页，不保留图片、复杂表格、原始 HTML 行号或字体排版。畸形 HTML 按标准库事件处理，超过 256 层或 100000 个事件拒绝。空文本、非 UTF-8、NUL 和超长内容明确失败，不回退到联网或 OCR。

M3.6b 已接入外部本地任务，支持 TXT/Markdown 和 .html/.htm（扩展名不区分大小写）。HTML 正文提取在材料审核后执行，随后沿用哈希、去重、敏感信息审核和脱敏、外部本地快照及增量流程。解析失败或空正文隔离为 invalid_or_empty_text；位置表示提取后规范化文本段落，不是原 HTML 行号。解析成功不表示人物事实或权利审核通过。PDF 与 DOCX 也已接入下述本地任务；URL 抓取尚未实现。


## M3.6c DOCX 解析核心

`local_docx.extract_docx(payload)` 仅从 ZIP 内的 UTF-8 `word/document.xml` 提取 WordprocessingML 主体段落与表格文字；不把 ZIP 解压到磁盘，不读取外部关系或执行宏。保留插入后的正文，忽略删除/移出文本及字段指令，字段已保存的显示结果可能保留，须人工核对时效。超链接只留下显示文字。

限制：不支持加密、旧 .doc、Strict OOXML 命名空间、页眉页脚、脚注尾注、批注、图片、OCR、复杂布局或浏览器渲染；不重现分页和字体，也不判断隐藏字体样式。扫描件或仅含图片时明确失败。位置只能表示提取后的段落，不是原始 Word 页码。修订取舍不是法律意义的最终定稿判断。

输入最多 5 MiB、ZIP 最多 1000 项且声明解压总量最多 40 MiB、正文 XML 最多 5 MiB、100000 节点和 256 层。重复条目、可疑路径、DTD/实体声明和非 UTF-8 XML 拒绝。M3.6d 已接入本地任务：材料审核后解析，复用脱敏、敏感审核、来源哈希、增量及失败隔离。坏 ZIP、空主体或不支持 XML 进入 invalid_or_empty_text 隔离，不尝试远程转换。


## M3.6e PDF 解析核心

`local_pdf.extract_pdf(payload)` 使用当前 Python 的本地子进程与可选依赖 `pypdf>=6.14.2,<7`，通过标准输入/输出传递正文，不生成临时原文文件、不访问网络、不执行附件或脚本。使用前在本机安装 `requirements-documents.txt`；开发测试依赖已包含它。普通 TXT/HTML/DOCX 使用不要求 pypdf。

输入上限 5 MiB、200 页、提取文字 2 MiB，子进程限时 30 秒；Flate 单次解压上限 10 MiB。超时会终止子进程，解析诊断不回传原文。这里没有操作系统级硬内存隔离，不能声称抵御所有恶意 PDF 资源消耗；超出支持范围明确拒绝，不自动重试或调用云转换。

加密文档不尝试密码；空白/仅图像文档报告 pdf_empty_text_or_scan，不伪造 OCR。多栏顺序、字体编码、表格关系和页眉页脚可能提取不准确，须人工复核；不把抽取段落当作原始页码。依赖缺失/版本不支持、页数/文本上限、损坏格式和超时各有明确错误码。M3.6f 已接入本地任务，材料审核后执行，并将这些明确错误码保存为隔离原因。部分 PDF 失败时保留其他有效输入，全部失败时进入 needs_inputs，不把失败文件记为成功解析。


## M3.6g 显式重新解析

普通 build 在材料未变时核验并复用快照，不自动因安装依赖或升级解析器重写内容。若要重新尝试此前隔离的文件，使用现有 local_distill.py 的 `build --job <id> --update --reparse`（仍需全局 library 与 confirm-local-storage）。这会在原材料审核仍有效的前提下建立新快照，报告 explicit_reparse=true；旧快照、审核与候选保留，新推理仍须单独发起。正文变化会使旧派生候选的当前性核验失败，需沿新快照重建。
