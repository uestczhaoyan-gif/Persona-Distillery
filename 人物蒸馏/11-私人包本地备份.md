# 私人包本地备份

状态：M1.5b/c 已提供默认只读预检和显式本地复制。备份是完整私人副本，保留 `local_only` 策略，包含包目录中的原文、日志、索引、头像及空目录；它不是可发布导出包。

在自己的本机终端执行，两个目录均不能被远程备份或同步：

```powershell
python 人物蒸馏/scripts/backup_persona.py "D:/PrivatePersonas/example-person" "E:/LocalBackups/snapshot-01" --confirm-local-storage
```

默认只输出文件数、字节数和预检计划哈希，不输出身份、路径、正文或文件清单，不创建目标。实际副本位于目标库的同一稳定 ID 子目录；目标已存在即拒绝，源目录与目标库不能重叠。

先校验完整 v2 manifest 与本地策略，再枚举整个包。Git 仓库、已知云同步位置、网络盘、链接/目录联接、迁移或备份未完成、占用锁、旧版 manifest 副本、无法完整读取的目录都会拒绝。上限为 10000 个文件、10000 个目录、总文件体积 10 GiB；预检会读取文件进行哈希，耗时取决于本机磁盘和包大小。

清单包括未在 manifest 声明的私人文件，因此不得把备份打包上传 GitHub、云盘或云 Agent。源目录外的私人原文、缓存、模型权重及外部备份不在本次清单内，不宣称已覆盖整台设备。程序只识别已知同步位置，自定义同步仍由用户确认。

## 显式复制与恢复

核对预检结果后，在同一台本机终端追加 `--apply --expect-plan-sha256 <预检返回的哈希>`，保留 `--confirm-local-storage`。目录、内容或策略变化导致计划哈希不同，必须重新预检。程序独占目标库备份锁，只创建新人物目录，不覆盖已有副本，不修改源包。

复制包括所有清单文件和空目录，逐文件检查大小与哈希，再重新验证源清单与目标全量内容。仅在全部一致时移除 `.backup-incomplete.json`。读取器拒绝存在该标记或库级 `.backup.lock` 的包。

完成的副本可在其原有安全本地目录中通过[本地预览](../直接对话/docs/私人本地预览.md)读取；若需恢复到其他库，仍用本工具复制到新的空目标，不覆盖原包。策略和 manifest 原样保留，恢复不会解除本地限制。

失败时保留未完成目录，没有自动覆盖、删除或续传。先检查磁盘和本地进程，保留现场或改用新的目标库重新预检；进程崩溃遗留锁时，须由用户核对进程是否已结束后处理，不能盲目删除锁。工具不提供撤回/删除功能，也不声称对恶意本机进程或断电提供事务保证。
