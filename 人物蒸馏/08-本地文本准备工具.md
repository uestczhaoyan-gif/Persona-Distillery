# 本地 TXT/Markdown 准备工具

这是蒸馏路线的解析与审核准备阶段：真实实现包括任务冻结、身份/授权/隐私关卡、UTF-8 TXT/Markdown 去重和切分、单文件隔离、不可变快照、恢复及增量变化检测。不会自动生成证据卡、情境记忆或人物设定，不会写正式人物目录或发布人物。

需要 Python 3.10+ 与 `python -m pip install -r requirements.txt`。输入默认不复制；用户选定的源目录和生成的 `人物蒸馏/runs/` 都只在本地，生成目录已被 Git 忽略。

## 用原创虚构夹具试跑

以下 PowerShell 命令在仓库根目录运行。样例只验证工程，不模拟真实人物：

```powershell
New-Item -ItemType Directory -Force 人物蒸馏/runs/local-fictional-001-incoming
Set-Content -Encoding utf8 人物蒸馏/runs/local-fictional-001-incoming/lesson.md "项目原创测试：做判断前，先写一个可以验证的问题。"
python 人物蒸馏/scripts/distill.py init --config 人物蒸馏/examples/local-fictional-upload.json
python 人物蒸馏/scripts/distill.py build --job local-fictional-001
```

`build` 返回 `identity_review`。真实数据须人工核对身份、处理权利、脱敏和范围之后，再记录自己的审核决定。对上述明确的虚构夹具，可以执行：

```powershell
python 人物蒸馏/scripts/distill.py approve --job local-fictional-001 --gate identity --reviewed-by fixture-reviewer --note "原创虚构测试文本，身份不对应真人"
python 人物蒸馏/scripts/distill.py approve --job local-fictional-001 --gate privacy --reviewed-by fixture-reviewer --note "虚构文本已检查，不含真实私人资料"
python 人物蒸馏/scripts/distill.py build --job local-fictional-001
python 人物蒸馏/scripts/distill.py status --job local-fictional-001
```

成功结果为 `review_required`，状态中的 `snapshot` 指向来源 CSV、实际片段 JSONL、输入清单、报告和审核提示。`ok=true` 表示命令完成，不代表人物可对话或可发布。所有片段固定标为 `private / local_only_text / local_only`，不将上传文本误标为人物原话。

## 审核与恢复

- 身份审核仅记录目标确认，不按数量推定资料充分。
- 在世、自己或已故私人个体改用[仓库外 v2 任务](13-本地蒸馏任务v2.md)，旧入口即使附有 consent 也不再创建仓库内任务。历史公共/虚构的旧工程夹具兼容保留；含真实私人材料的新任务同样使用 v2。
- 每次隐私审核绑定输入及授权文件指纹。新增、移除或改变文本之后重新审核，再用 `build --job <id> --update` 建立新快照；旧快照和来源 ID 保留。
- 检测到邮箱、手机号码或疑似凭据后进入 `sensitivity_review`。人工审阅本地文件后可以登记 `approve --gate sensitivity ...`；邮箱/手机号在输出中确定性遮罩，疑似凭据文件始终隔离，需要清理原始输入后重新审核。
- 这不是完整隐私检测或自动第三方授权工具。人物参与者映射、聊天归属和多说话人导入尚未实现，配置 participant_map_file 会明确拒绝；请先提供人工脱敏和确认归属的文本。

相同输入重跑不会创建新快照。变化后的内容分配新来源 ID；消失的来源列入新报告的 withdrawn_source_ids，已有快照保留供本地审计。不同来源的文本一致只证明内容重复，unique_text_sources 不代表来源独立性已核实。

最多 500 个文件，每文件 5 MiB；仅接收 UTF-8（含 BOM）TXT/Markdown。损坏、空文本、二进制、符号链接和其他格式列入隔离报告，其他文件继续。全部不可用时返回 `needs_inputs`。规范化包括换行、NFC 与行末空白，定位明确标为 normalized input；行/字符范围可回到输入清单的校验值。长行按字符边界切分，后续证据编写者仍须检查语义上下文。

job.json 和私有路径配置被冻结，不允许原地改变；需要新配置时创建新 job_id。单任务文件锁阻止重入；崩溃后先确认没有运行进程，再人工检查并移除该任务自己的 `.lock`。未被 state.json 引用的快照是中断产物，不作为已完成结果。

下一步按既有 [标准流水线](01-标准流水线.md) 人工提炼证据、情境和人物规范，并评测、审核后才考虑正式人物包。自动抽取、网络采集、PDF/DOCX、OCR、音视频、自动合成和发布仍在后续路线中。
