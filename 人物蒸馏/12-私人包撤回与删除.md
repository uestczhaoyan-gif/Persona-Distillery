# 私人包撤回与删除

状态：M1.5d/e 已实现默认只读预检和显式本地删除；只有带执行参数的命令才删除。

在自己的本机终端指定一个完整的外部 v2 本地人物包：

```powershell
python 人物蒸馏/scripts/delete_persona.py "D:/PrivatePersonas/example-person" --confirm-local-storage
```

默认输出文件数、目录数、总字节数、计划哈希和无法代删的范围。`--show-plan` 可在本机交互终端显示完整绝对目标和包内路径、大小及哈希，拒绝管道或重定向；清单可能暴露私人文件名，不要传给云 Agent。

预检包含包目录内全部文件与空目录，而非只看 manifest 已登记文件。因此包内原文、证据、记忆、索引、头像、日志、缓存和生成稿都在清单内；包目录本身也在拟删除范围。父级私人库、其他人物包及目录外文件不在其中。文件、目录或内容变化会改变计划哈希。

以下内容无法由这一包目录操作代为清除，结果会明确列出：

- 包外原始输入、缓存和生成文件。
- 其他本地副本、备份、远程副本和第三方应用中的数据。
- 正在运行的进程里的对话记忆，需另行关闭会话。
- 文件系统快照、回收站及存储介质残留；本工具不是安全擦除工具。

仅处理身份与目录相符的完整 private/local_only v2 包。仓库、已知同步目录、网络盘、链接、占用锁或未完成包会被拒绝；无法完整枚举时停止。中断迁移/备份的清理需要先本地核查，不以缺失 manifest 为由递归删除未知目录。

## 显式删除

在本机终端核对 `--show-plan` 展示的绝对包路径与完整清单后，使用同一包路径，追加 `--apply --expect-plan-sha256 <预检哈希> --confirm-delete`，保留 `--confirm-local-storage`。这是不可撤销的普通文件删除，不进入本工具的回收站；如需保留合法本地副本，先完成独立备份。

执行先复核计划哈希，再取得库级 `.deletion.lock` 并重新预检。程序只逐个删除计划内、大小及哈希未变的文件，最后移除空目录和人物包目录，不递归清理未知内容。新增文件或内容变化会使操作停止，已删除文件不会自动恢复。

开始删除前写入 `.deletion-incomplete.json`，保存原计划及哈希用于本地恢复；聊天读取器和备份器拒绝该状态。中断会保留标记和剩余文件，成功才移除标记。当前不提供续删入口，发生中断先关闭相关会话、保留现场并在本机检查；不要通过删标记把残缺包当成正常包。进程崩溃遗留锁时，先核对对应进程再处理。

完整成功仅表示所选包目录已经删除。其他备份、外部原文、已运行进程的记忆、已发出的模型请求和存储介质残留仍需单独处理；程序不会报告它们已被撤回。对抗恶意本机进程或断电事务恢复不在本节点保证范围内。
