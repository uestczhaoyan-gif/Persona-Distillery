# 本地应用

工作台已接入圆桌与演讲，复用各模块的状态机和本机模型运行器。
服务只绑定 `127.0.0.1`，不加载外部脚本、字体或统计。当前只接历史公共人物，保留草稿预览确认。
不读取外部私人库。会话仍保存在原圆桌目录，不建立第二份业务数据。

## 启动

安装仓库 `requirements-dev.txt` 中的依赖后，从仓库根目录运行：

```powershell
python 本地应用/scripts/server.py --port 8765
```

在浏览器打开 `http://127.0.0.1:8765`。使用数字回环地址，不能用外网 IP 或其他主机名。
服务退出后重新运行即可从“最近的圆桌”打开已提交记录。终端 Ctrl+C 停止服务；不要在模型生成中关闭进程。

## 圆桌操作

1. 填写议题和目标，选择至少两人及回合上限；预览草稿需勾选确认。当前接入有圆桌适配层的孔子、庄子、费曼。
2. 创建圆桌，填写已经安装且运行中的 Ollama 模型名，确认使用本机服务。
3. “开始讨论”或“继续一个回合”分别请求一次模型；生成中仍可暂停、插话或结束。暂停只拒收迟到结果，不承诺停止模型计算。
4. 达到回合上限或点击“结束讨论”后，点击“生成讨论稿”。模型失败时保留之前记录，修复条件后继续或重试。
5. 查看、下载逐轮记录、讨论稿、依据附录和结构化稿件。下载只保存到本机浏览器下载位置，不代表已获公开发布审核。

工作台通过真实后端保存和回放，不预填假发言；不会自动下载模型。未启动 Ollama 时，创建和读取仍可用，生成会显示失败并保留记录。
意外退出后若生成票据仍在，可先暂停再继续；编辑锁恢复见[模型运行器](../圆桌会议/12-模型回合运行器.md)。

## 边界与验证

仅本机回环 HTTP；Host、Origin、会话期请求令牌和内容安全策略限制其他站点操作。令牌不放到 URL，无 CORS 放行。页面只用文本节点呈现材料，不执行模型输出中的 HTML。API 不提供任意文件读取或外部私人库入口。

HTTP 集成测试使用原创模型桩，覆盖创建、两个实际状态回合、成稿和回放，以及预览确认、并发暂停、重复请求与访问边界。
浏览器已检查创建、模型配置缺失提示、逐轮记录读取、刷新恢复、实际下载和页面显示。真实模型、移动窄屏操作及人工内容质量仍待验证；故事与统一人物库将在后续节点接入。

M8.1 完整回归 374 项（373 通过、1 Windows 符号链接环境跳过），仓库校验通过；总数含未提交暂缓批次模块的 3 项测试。

## 演讲工作台

导航选择“定题演讲”，或打开 `/lecture`：选择历史公共人物，填写主题、听众、目标、分钟与资料时间点，确认草稿预览后保存简报。
可选补充多条公开来源及陈述，独立于人物记忆；这不会自动联网，也不代表完成事实核查。
依次生成人物提纲、演讲正文；有稿件后可填写修订要求，每版保留旧文件。可查看和下载简报、资料、提纲、正文和来源附录。
生成期间没有取消按钮，不自动重试；失败后原简报和已提交稿件保留。正在生成时下载可能因会话锁返回提示，生成结束后可重试。

演讲 17 项针对性测试通过，包含 3 项 HTTP 流程；圆桌 5 项 HTTP 回归通过。浏览器验证保存、读取、缺少模型配置提示，无前端报错。真实内容、移动窄屏及演讲页面下载交互仍待进一步验收；下载接口已在 HTTP 测试验证。
