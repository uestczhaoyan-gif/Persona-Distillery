# 治理与边界

## 核心原则

1. **证据可追溯，表达不僵化。** 系统只能基于可记录的材料建模；无法证明的内容在需要核验时标为推断或材料不足，默认自然对话不强行给每句话贴标签。
2. **不冒充真人。** 交互界面明确标识为基于材料的“人物视角模拟”，并如实说明材料是公开来源、本人陈述还是用户回忆；不得称为本人或暗示本人授权。
3. **时间有边界，方法可迁移。** 人物不能被写成知道身后发生的事实，也不能把新事实冒充其真实意见；但用户提供当代事实后，可以让其既有理解、判断和表达方式自然分析这个新问题，不必每轮先做年代声明。
4. **来源可复核。** 重要事实、原话和生平断言要链接到来源 ID、位置（页码/时间戳/段落）和摘录；人物视角下的新推理不要求逐句回链，但不得伪装成原话。
5. **从严处理在世人物。** 对私密材料、聊天记录、声音/肖像、敏感生活史，必须得到明确的、可撤回的授权。

## 资料分级

| 级别 | 资料例子 | 用途 | 规则 |
| --- | --- | --- | --- |
| A：一手公开 | 著作、本人演讲、署名文章、公开访谈原片 | 核心观点与措辞 | 优先使用，保留精确出处 |
| B：可靠记录 | 经核验的传记、访谈实录、机构档案 | 补足背景和事件 | 标明作者与可能转述链 |
| C：二手解读 | 评论文章、他人回忆、课程讲解 | 提出检索线索与反例 | 不可单独支撑关键主张 |
| D：私密或敏感 | 聊天记录、私人信件、未公开录音 | 仅限授权研究 | 加授权说明、访问控制和删除机制 |
| E：不可靠 | 无出处名言、拼接短视频、营销文案 | 不进入证据库 | 可留作待核线索，但不作为训练/回答依据 |

## 版权、隐私与人格权

- 保存"元数据和短摘录"不等于取得全文再发布的权利。原书、视频、付费文章和字幕应保留原始链接/购买信息，遵守其许可证；不要把受版权保护的全文上传到公开仓库。
- 处理聊天记录前要移除第三方的姓名、联系方式、地址、健康与财务等信息；涉及多方对话时，不能只取得其中一人的许可。
- 不以人物体生成可被误认为真实的语音、视频或新近表态；不用于商业背书、诈骗、政治动员或法律/医疗等高风险结论。
- 收到本人或权利人的删除/更正请求时，停止发布，记录请求，移除相应材料、索引与衍生内容，并重新构建版本。

## 回答依据的四种状态

系统应在后台保存这四种状态。默认自然对话不逐段显示标签；用户请求依据、内容敏感或把握不足时，再以自然语言展开：

- **直接证据：** 有明确原话或行为记录。
- **综合概括：** 多条材料一致支持的总结。
- **假设推演：** 根据既有框架作出的可能判断，不是事实。
- **未知/材料不足：** 没有足够证据时的正确回答。

## 授权最小记录

若人物在世，`00-profile.md` 中至少写明：授权人、授权范围（资料/用途/发布范围）、有效期、是否允许风格模拟、是否允许对外访问、撤回联系方式和删除流程。没有记录就不把私密材料加入系统。

## 自动蒸馏的强制关卡

- **公开人物 + 网络资料：** 自动搜索前确认人物身份；发布前人工抽查来源、争议观点和肖像使用方式。
- **身边人物 + 上传资料：** 处理前必须确认资料提供者有权使用这些材料；若人物在世且可识别，必须记录本人授权或保持为仅本地私有草稿。
- 上传资料中的第三方不因"文件由用户提供"而自动同意被蒸馏。系统应默认检测并遮蔽第三方姓名、联系方式和敏感信息；多人聊天、会议录音等在授权不清时停止处理。
- 受限人物的构建、摘要、头像、OCR、转写、embedding 和对话均不得调用外部遥测或远程模型，不提供以勾选确认解除本地限制的通道。公共可处理包的服务声明与发布审核分别验证。
- 自动化可以生成草稿，不能自动宣称已获授权、来源可靠或可以公开发布。最终发布必须是单独的人工动作。

## 新规划 M1 的本地路径

在世公众、在世私人、已故私人，以及包含敏感或非公开回忆材料的包使用仓库外私人库；`execution_policy` 与 `distribution_policy` 均为 `local_only`。保留来源和资料使用依据，不把用户回忆当成本人确认。质量 `readiness` 不授予传播权限。

六类人物可通过[独立终端预览](../直接对话/docs/私人本地预览.md)进入本地只读对话；这不是公开发布，也不表示完整蒸馏已经实现。原有 Agent 快捷入口不扫描私人库。受限正文、摘要、头像参考及模型输出不得传给云 Agent。中央授权、本机模型预检、外部库与路径验证都有工程测试；私人包备份/删除及中断恢复已有本地实现；真实模型质量、完整人物合成及其他功能仍待后续验收。

删除/撤回要求覆盖原文、证据、索引、头像、缓存及衍生文件；当前工具可显式删除选定人物包内的文件，但包外原文、任务快照、其他备份与活动进程不在范围内；先停止相关使用并由用户本地检查这些范围，不能宣称全设备已自动清除。
