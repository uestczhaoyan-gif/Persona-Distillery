# 人物卡与头像视觉规范

## 统一选择

全项目的人物头像统一采用：**现代编辑插画式半身人物肖像**。

它是一种克制、清晰、略带温度的插画风格：人物有可辨识的轮廓和表情，但不追求照片级真实；有时代或职业线索，但不堆砌符号；有个性，但不把人画成夸张的刻板角色。

之所以不统一为 Q 版或某一种动漫风格，是因为项目未来会覆盖哲学家、科学家、艺术家、企业家、运动员和普通人的经验档案。编辑插画既足够通用、严肃，也仍然有亲近感，适合人物卡、单人对话和圆桌座位。

## 固定画面规则

| 项目 | 规则 |
| --- | --- |
| 构图 | 正方形 1:1；头肩或胸像；人物居中，保留边缘呼吸空间 |
| 视角 | 正面或轻微 3/4 侧身；眼神自然，不用夸张表情 |
| 背景 | 纯色或极简几何/纸张肌理；不用复杂场景 |
| 色彩 | 每人 2--4 个主色；同项目保持低饱和、协调的总体色调 |
| 区分方式 | 发型、服饰轮廓、姿态和**最多一个**相关小道具 |
| 避免 | 照片写实、夸张漫画脸、猎奇符号、政治宣传构图、文字、水印和品牌标志 |
| 呈现 | 人物图旁或卡片内标为"风格化人物图"；不声称是真实肖像或历史原图 |

## 文件格式与尺寸

- **保真母版：** `assets/avatar.png`，`1024 × 1024`、sRGB、PNG。PNG 适合保留插画边缘、后续编辑和跨平台兼容。
- **界面优化版：** `assets/avatar.webp`，从 PNG 母版导出。网页中优先用 WebP 以减小加载体积，不能显示 WebP 的场景回退到 PNG。
- **不建议：** 只保存 JPEG（反复编辑易损失细节），或让每个人使用不同尺寸、不同画风。

## 当前统一生图参数

以下是项目所有者在 ChatGPT 生图网站中采用的统一界面设置：

| 设置 | 默认值 |
| --- | --- |
| 平台 | ChatGPT 生图网站 |
| 模型界面标签 | `gpt2`（按网站界面原样记录，不推定为 API 模型名） |
| 画幅 | 竖图 1024 |
| 质量 | 标准 |
| 输出格式 | PNG |
| 背景 | 自动 |
| 审核 | 宽松 |

这些是**生成平台参数**，不替代项目的最终资产规范。下载后保留原图为 `assets/avatar-original.png`，再依据实际构图生成正方形 `avatar.png` 与 `avatar.webp`。每张头像还应在 `assets/avatar-metadata.md` 记录实际平台、界面模型标签、日期、文件尺寸和项目所有者的发布授权确认。

## 头像生成通用提示词

```text
Use case: stylized-concept
Asset type: reusable character-card avatar for a conversation and roundtable application
Primary request: a respectful, clearly stylized editorial illustration portrait representing <人物名称>, not a photorealistic likeness.
Subject: <有资料基础的外貌、发型、服饰轮廓和一个领域线索>
Style/medium: modern editorial character illustration, subtle stylization, clean readable silhouette, cohesive with a collection representing people across eras and professions
Composition/framing: square 1:1, centered head-and-shoulders or bust portrait, front or gentle three-quarter view, generous margin
Scene/backdrop: a flat or minimally textured abstract background, no detailed location
Lighting/mood: thoughtful, calm, approachable
Color palette: <2--4 个协调的低饱和颜色>
Constraints: no text, no watermark, no logo, no photorealism, no historical-event recreation, no political endorsement, one subtle prop at most
Avoid: caricatured ethnicity, mocking exaggeration, specific anime franchise style, cluttered background
```

## 审核清单

生成后确认：在 64 像素缩略图下仍能辨识；没有错误文字或冒犯性符号；人物之间的构图和色调一致；不把推测性的外貌或争议性象征画成确定事实；保存最终提示词、日期和人工审核结论。
