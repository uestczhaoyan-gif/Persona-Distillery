## 可复现命令

从仓库根目录运行，需 Python 3.10+：

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
python tools/validate_repository.py
python 直接对话/scripts/persona.py list
python 直接对话/scripts/persona.py doctor kongzi --preview
python 直接对话/scripts/persona.py search 孔子 学习 --preview --top-k 3
```

`--preview` 仅表示已有授权的历史公共人物本地预览，不生成授权或改变 manifest。四个人物分别执行 doctor 和 context 命令，检查入口、材料及容量。完整测试不调用真实模型，也不访问模型云服务；HTTP stub 只绑定 127.0.0.1。沙箱禁止本机回环连接时，该项需在允许连接的测试环境运行。Windows 沙箱临时目录受限时，可建立被忽略的 `.work/tmp` 并为当前测试进程设置 TEMP/TMP。

本轮额外执行了四个人物各自 doctor/search/context 共 12 项 CLI 烟测、英文入口的精确证据 ID 查询，并核对本轮相关文档的 64 个本地链接。词汇检索不做翻译，费曼的英文 experiment 查询在现有中文材料中无匹配；用“实验”查询取得结果，未把空结果误记成检索故障。

另执行了虚构上传样例及圆桌票据文件往返；命令和输出边界分别见 [文本准备工具](../人物蒸馏/08-本地文本准备工具.md) 与 [圆桌状态工具](../圆桌会议/11-本地状态工具.md)。本地结果与测试临时产物保持在被 Git 忽略的运行目录，不随代码上传。

## 尚未验收和后续入口

- 真实本地模型的工具兼容性、tokenizer 容量、自然对话质量、去名盲评与人物辨识度：尚未实验。字符预算和 HTTP 桩不能代替这些结果。
- 资料权利、同意有效性、隐私遗漏、证据忠实性：仍须人工审核。工程检查只验证配置和基本线索，不作法律判断或完整脱敏保证。
- 上传准备停在 `review_required`；自动证据提炼、人物合成、参与者映射、PDF/OCR、音视频和正式发布尚未实现。
- 圆桌原型不调用模型或自动主持，不验证论证语义；`accepted=true` 只证明工程协议通过。完整文章由外部 Agent/人工提供和审核。
- 远程模型 API、联网事实台、Web、故事、演讲、语音和生产部署保留在既有路线中，均不属于本轮完成标志。

下一轮应由使用者选定明确范围，例如真实本机模型的保留题实验，再建立独立验收条件。`ENGINEERING_COMPLETE` 表示本轮六项工程合同完成，不表示整张长期蓝图或人物公开发布已经完成。
