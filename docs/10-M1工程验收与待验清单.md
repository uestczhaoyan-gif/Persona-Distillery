## 待验收与范围限制

1. **真实模型依赖：** 本轮复查未在 PATH 找到 Ollama，默认本机 `/api/tags` 不可访问。需要用户设备上的可信本机模型服务、模型版本及容量，之后先按 [M0 合同](09-M0基线与评测合同.md)建立真实基线，再验证私人虚构夹具试聊。不得以云端代替受限人物推理。
2. **真实质量证据：** 未运行自然度、人物辨识度、事实回链的真实回答实验，也没有两名人工独立评审。已通过单元测试不等于人物蒸馏质量通过。
3. **尚未实现的功能：** OCR、转写、embedding、生图、私人圆桌/演讲/故事、公共 v2 发布器及完整候选人物合成仍关闭或拒绝；不因中央策略函数存在就开放这些能力。
4. **删除边界：** 人物包外的原始输入、任务快照、授权/审核记录、其他备份、活动会话和物理介质残留不会自动清除。工具报告这些范围；不作“全设备一键撤回”的声明。
5. **本机信任边界：** 回环地址和云模型标记检查不能证明另一进程不会转发请求。本机模型服务及设备外联配置由用户管理；本项目不是 OS 网络沙箱或防复制系统。
