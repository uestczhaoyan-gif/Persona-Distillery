## 设计选择

- 选择鲁迅而非孔子作为第二个盲测人物，因为本人可定位语料更丰富，体裁和时期跨度足以同时观察稳定关切与观点变化。
- 人物辨识度放在注意力和推理选择上，不要求民国句法、名句和持续讽刺。
- 默认内化记忆对话：读入人物包后直接思考，接受用户给出的当代事实，不自动联网，不展示检索过程，不把“不知道”设为开场仪式。
- 规则只保留不冒充、不伪造、不混淆文学人物与作者、不给现实伤害背书等底线。
- 小说证据严格标注为情境、象征或人物机制；直接论断优先使用杂文、演讲和序言。

## 警告与缺口

- 当前依赖公开数字文本和版本目录，尚未逐页与权威纸本《鲁迅全集》校勘；逐字引文发布前必须另行核对。
- 本地增强层已登记一批实际分析过的公有领域作品及其转录入口，但尚未保存批量全文；现代校注、排版、数据库和扫描件仍须单独做权利判断。
- 来源台账中的 `content_checksum` 为空，因为未将远程全文批量下载进工作区；本次 JSONL 校验值只覆盖规范化摘要，不是远程全文指纹。
- `raw/` 没有作品全文；本次 `chunks.jsonl` 从人工审核卡迁移，均标为 `summary` 和非直接引语，不能冒充原始转录。
- 当前 `vectors.npy` 是确定性的字符 n-gram 词汇向量，不是模型语义 embedding；索引清单明确标记 `semantic_embeddings=false`。
- 论战杂文高度依赖当时对象和政治语境，人物体不得把文中敌我关系直接迁移到当代个人和群体。
- 鲁迅关于女性、家庭和社会的材料有重要洞察，但不能替代当事人的当代经验或专业研究。
- 头像原图已保留，标准 PNG/WebP 已嵌入 sRGB 并通过全尺寸与 64 像素检查。
- 尚无独立 CLI 对话运行时；Agent 直读模式需要在全新会话中检验是否真正内化人物包。
- 定题演讲已允许私有 Agent 预览，但尚未完成主题覆盖、长文连贯性、当代事实核验和口头可讲性评测。
- v0.1 尚未完成人工活人感和有用性评测，不升级为 `chat-ready`。
