# 费曼本地研究增强层

这里承载仍受保护的书籍、访谈、课程与录音的本机研究记录。当前自动建立的是空白受控层；项目没有把《费曼物理学讲义》、回忆录或传记全文复制进来。公开人物包中的新增情境记忆只保存基于已登记来源形成的原创、非连续摘要。

逐源记录购买/借阅/公开网页依据后，原文放入 `raw/`，默认 `local_only`。Codex/Claude Code 直读不得打开原文；只有通过 [`../../../人物蒸馏/scripts/export_agent_overlay.py`](../../../人物蒸馏/scripts/export_agent_overlay.py) 审核导出的 `agent_summary` 才能进入远程会话。完整规则见 [`../../../人物蒸馏/06-受保护材料处理规范.md`](../../../人物蒸馏/06-受保护材料处理规范.md)。
