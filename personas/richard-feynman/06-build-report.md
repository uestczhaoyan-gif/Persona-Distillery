## 警告与缺口

- AIP 口述史目录和访谈范围已核验，但逐场转录页面部分不可访问；不得假装已经逐字分析全部访谈。
- 多本传记、回忆录、书信集和讲座书只完成编目或局部核验，未复制或批量保存受版权保护全文。
- 本地增强层已建立逐源权利台账，但 `raw/` 仍为空；它不会暗示项目已经读取用户未提供的纸书或付费全文。70 条新增情境记忆是基于已登记且实际分析过的公开页面和既有研究记录形成的非连续原创摘要。
- `raw/` 没有远程原文；本次 `chunks.jsonl` 从人工审核卡迁移，均标为 `summary` 和非直接引语，不能冒充原始转录。
- 当前 `vectors.npy` 是确定性的字符 n-gram 词汇向量，不是模型语义 embedding；索引清单明确标记 `semantic_embeddings=false`。
- 物理方法的核心结论优先来自论文、课程、完整演讲和 NASA 报告；轶事只作低权重背景。
- 对私生活、性别态度与英雄叙事的处理包含后世评论，应与一手材料区分，不把价值判断伪装成原话。
- 互联网通行的固定“四步费曼技巧”暂未找到可定位的一手出处；目前只标作后人归纳。
- 头像已完成尺寸、色彩和 64 像素缩略图检查；项目所有者已补录生成平台、界面模型标签、生成参数并确认可随项目开源。平台条款与第三方权利未作独立法律审查。
- 尚无独立 CLI 对话运行时；Agent 直读模式已完成首轮人工试聊，但 v0.2 的自然度、人物辨识度和边界仍待新会话复测。
- 定题演讲已允许私有 Agent 预览，但尚未完成主题覆盖、长文连贯性、当代事实核验和口头可讲性评测。
- v0.1 首轮 Agent 试聊显示：逐条规则和默认联网会把人物压成通用研究报告。v0.2 起改为内化记忆、自主回应、依据用户给出的事实先行思考，并增加活人感盲测；尚待新会话复测。
