# 人物快捷入口

本文件定义人物选择和准入，回答行为统一使用 [Agent 执行契约](prompts/agent.md)。代码路径均相对仓库根目录。

## 识别范围

仅当用户实际要求启动或切换人物时识别入口。代码块、引号中的示例、询问命令含义和修改项目的请求不触发人物模式。

| 输入 | 动作 |
| --- | --- |
| `/孔子`、`/鲁迅`、`/费曼`、`/庄子` | 选择对应人物 |
| `/persona kongzi` | 按稳定 ID 或别名选择 |
| `人物 孔子`、`进入孔子人物视角`、`我想和孔子交流` | 等价自然语言入口 |
| `/孔子 我读了很多书，却不会判断。` | 选择人物，后文作为第一问 |
| `/人物` | 列出人物和草稿状态，不加载记忆 |
| `/退出`、`退出人物视角` | 恢复普通助手，不关闭客户端 |

命令头与问题用空白或换行分隔。完整的自然语言入口单独出现时才作为选择请求；后续可以换行附带问题。根据 [别名表](persona-aliases.json) 或现有目录稳定 ID 精确匹配名称，英文忽略大小写。未知人物或重名停止并说明，不作模糊猜测。

## Agent 调用步骤

1. 拆出人物名和可选问题，完整保留问题原文。不得把用户整条消息拼入 Shell 命令。
2. 使用参数安全传给解析脚本，例如 `python 直接对话/scripts/resolve_persona.py 孔子`。列表使用 `--list`。脚本只生成 JSON 计划，不开始聊天。
3. 先读计划中的 manifest，再按 `load_files` 的顺序完整读取文件，直接对话适配层最后加载。不能只读文件名就开始模拟。
4. 如果用户当前会话已经明确授权预览而未保存到本地，可加 `--preview`。没有授权时不得自行添加。
5. 读取失败、计划无效或必读文件缺失时说明具体原因，不退回通用角色扮演。成功后依据用户问题自然回答，不在正文输出加载过程、角色标签或固定开场说明。平台要求的工具提示仍由宿主决定。

没有 Python 时可按相同规则手动加载：由别名表和人物目录找到稳定 ID，验证 manifest 身份和 `direct_chat=true`；公开使用要求 `visibility=public` 且 readiness 为 `chat-ready/simulation-ready/publish-ready`；其他情况仅对 `historical_public` 且已有预览授权继续。按契约读取 manifest 声明的必读文件，拒绝越出人物目录或指向 raw、research.local、隐藏目录的路径，再读模块适配层。

## 预览范围与会话状态

本地授权使用 `.persona/preview.local.json`，格式见 [空白示例](_template/preview.example.json)。它只列出用户同意的稳定 ID，范围为 `local_read_only`；不继承到新增人物、不修改人物发布状态、不授予原文访问或公开发布权限。已有授权不重复询问；首次未获授权时仅确认一次。用户要求保存时才更新本地清单，保留其他已授权 ID。

切换时重新加载目标人物，不把前一人物的观点作为新人物的历史证据。用户当前问题可延续。退出后恢复普通助手，不写文件、不删除历史、不调用客户端 `/exit`。严格隔离或盲评请新建任务。

## 宿主适配

Codex 通过项目根目录 [AGENTS.md](../AGENTS.md) 路由；其他 Agent 没有自动读到时，发送“读取 AGENTS.md，然后进入孔子人物视角”。新任务从仓库根目录开始；仓库可以改名，路径不加 `3-人物/` 前缀。

`/孔子` 和 `/persona` 都不是客户端内置命令，也不会自动出现在原生命令菜单。若客户端拦截斜杠，请用 `人物 孔子`。本地配置是预览偏好，不是服务器访问控制。

官方依据：[AGENTS.md 项目指令](https://learn.chatgpt.com/docs/agent-configuration/agents-md)、[客户端命令](https://learn.chatgpt.com/docs/developer-commands?surface=cli)。
