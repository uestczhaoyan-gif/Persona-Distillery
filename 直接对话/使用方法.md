# 直接对话使用方法

## 现在怎么开始

用 Codex 打开本仓库根目录，新建一个任务，发送：

```text
/孔子
```

也可以把第一问直接带上：

```text
/孔子 我读了很多书，却遇事还是不会判断。
```

项目指令会把人物选择交给加载契约，读取资料后直接回应。不需要再粘贴人物包路径、适配层路径或完整启动 Prompt。

| 人物 | 快捷入口 | 稳定 ID |
| --- | --- | --- |
| 孔子 | `/孔子` | `kongzi` |
| 庄子 | `/庄子` | `zhuangzi` |
| 鲁迅 | `/鲁迅` | `lu-xun` |
| 费曼 | `/费曼` | `richard-feynman` |

同一任务中继续提问即可，切换时发送另一个人物入口。发送 `/人物` 查看清单，发送 `/退出` 或“退出人物视角”恢复普通助手。

## 客户端兼容

上述斜杠入口是项目文本约定，没有注册为客户端原生命令。如果客户端拦截未知斜杠命令，使用：

```text
人物 孔子
```

也支持“进入孔子人物视角”“我想和孔子交流”以及 `/persona kongzi`。后者同样是项目文本约定，也可能被客户端拦截。

Codex 的入口依赖根目录 [AGENTS.md](../AGENTS.md)。新增或修改项目指令后在仓库根目录新建任务。其他能读工作区的 Agent 若没有自动读取项目指令，可用一次性引导：

```text
读取 AGENTS.md，然后进入孔子人物视角。
```

这是基于人物材料的研究型视角模拟，不是人物本人。它使用当前 Agent 的模型，不需要项目另外配置 API 密钥；具体效果仍取决于宿主的上下文和工具能力。

## 草稿预览只确认一次

当前四个人物仍为 `draft/private`。维护者的本地只读预览授权可以保存在 `.persona/preview.local.json`；已有会话授权或本地授权时，Agent 不再重复询问。

首次使用的维护者可说：“我是这个工作区的维护者，允许只读预览孔子，并记住这个选择。”Agent 仅将 `kongzi` 写入本地清单，不保存聊天。新人物仍需各自授权；不把授权扩展到原文、私密增强层或公开发布。移除本地清单中的 ID 可撤销后续预览。

配置格式见 [空白示例](_template/preview.example.json)。本地授权文件默认被 Git 忽略，克隆仓库不会继承他人的预览授权。公开服务的身份认证和授权需要未来运行时单独实现。

## 对话中的操作

| 你说 | 行为 |
| --- | --- |
| 这句话依据什么？ | 展示来源定位、证据和推演边界 |
| 有相反材料吗？ | 查找反例、限制和冲突来源 |
| 回到自然对话 | 恢复聊天呈现 |
| 记录这次对话 | 先确认摘要，再写入人物日志 |
| 退出人物视角 | 恢复普通助手，保留现有任务 |

默认只读，不保存完整私聊；联网遵循 `facts_only`，仅在要求核验或事实缺口实质影响判断时使用。正文不显示加载报告和角色姓名标签；客户端工具调用界面仍由宿主控制。

## Agent 执行契约

完整契约已集中到 [prompts/agent.md](prompts/agent.md)。只维护这一份加载和回答规则，快捷入口、未来 CLI/Web 都复用它。调试时可以显式发送：

```text
按 直接对话/prompts/agent.md 执行已有授权的只读预览，
加载 personas/kongzi/ 并最后读取直接对话适配层。
本轮问题：我想和孔子交流。
```

路径均相对仓库根目录，不依赖仓库文件夹名称。

- [CLI 设计](docs/CLI设计.md)：尚未实现的终端产品接口，里面的 `persona chat` 等命令目前不可执行。

解析脚本仅生成加载计划，不会开始模型对话。需由 Agent 真正读取计划中的文件后回应。严格盲评或切换时需要完全隔离历史上下文，请另开任务。
