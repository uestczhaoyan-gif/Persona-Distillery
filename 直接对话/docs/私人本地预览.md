# 私人 v2 人物包的本地预览

状态：M1.5a 工程入口。支持六类人物的本机只读预览，真实模型容量、人物质量和人工评审尚未验收；草稿不等同完整人物交付。

## 准备

1. 本机安装 Python 3.10+ 和仓库 `requirements-dev.txt` 中的依赖；安装依赖时不要传入私人材料。
2. 自行安装并启动可信的本地 Ollama，选择已下载模型。确认服务不会把推理转发到远端，设备侧限制其外联；不要将任意本机代理端点当作隐私保障。
3. 人物包放在仓库外、非 Git、非同步的本地目录，入口为 `manifest.v2.json`，执行与传播均为 `local_only`。已有 v1 包通过[迁移工具](../../人物蒸馏/10-人物包迁移工具.md)预检后生成。私人源材料本身也须位于本地私人位置。
4. 使用自己的本机终端，关闭录制、同步、共享和日志采集。不要让云 Agent 读取私人 manifest、正文、模型输出或终端记录。

目录和模型名以下均为占位示例，替换为自己的本机值；不要把真实资料或问题写在命令行参数里。

```powershell
python 直接对话/scripts/local_persona.py "D:/PrivatePersonas/example-person" --model YOUR_LOCAL_MODEL --preview --confirm-local-storage --confirm-local-model
```

两个确认参数分别表示库未被远程备份/同步，以及本机模型服务可信且不转发请求。`--preview` 表示构建者明确预览草稿或尚未启用对话能力的包；它不改变质量、类型、传播或执行策略，也不授权公开发布。程序不保存这些确认，不会替用户扫描所有同步软件。

## 使用

启动时会说明模拟身份、本地使用边界与不保存会话。直接输入问题即可；`/new` 清空本轮记忆，`/exit` 退出。可以自然追问依据，但本阶段不提供检索工具或专门的证据审计命令。

私人命令没有 `--prompt`、上下文导出、保存或恢复功能；拒绝管道输入和标准输出/错误输出重定向。它不写人物包或聊天日志，不执行模型返回的任何工具调用。外部软件仍可能录屏或记录终端，因此这些检查不等于防复制技术。

每轮只允许经过元数据检查的回环 Ollama 连接，并重新核对人物包。包文件改变时必须退出后重新启动；已读包变更不会悄悄进入旧会话。出错轮次不会进入会话历史。

`--max-chars` 默认 100000，仅限制人物上下文字符数，超限时拒绝加载而不截断；`--num-ctx` 默认 32768。字符数不等于模型 token 数，也不保证服务不会自行截断输入，必须依据真实模型验证容量。会话历史超限时使用 `/new`。

## 当前边界

- 六类人物按相同本地预览流程处理，不能靠改类型、质量标签或文件后缀解除本地限制。
- 程序拒绝网络盘、已知云同步路径、Git 仓库、链接/目录联接、未完成迁移和旧版入口副本。自定义同步软件仍需用户确认。
- 这里只接入直接对话；私人包的圆桌、演讲、故事、OCR、转写、生图及删除工具尚未交付；[本地备份](../../人物蒸馏/11-私人包本地备份.md)已有独立命令。中央授权函数存在不代表各功能已经接入。
- 完整新人物必须另行完成实际 AI 头像和质量验收；受限人物头像也必须在本机生成，不向云生图服务发送资料。
- 本机服务是否可信属于设备配置边界；本项目不提供操作系统级网络隔离，也不能阻止用户修改代码或自行传播内容。
