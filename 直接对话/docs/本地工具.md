# 本地检查、检索和上下文编译

需要 Python 3.10+，这些命令仅使用标准库，不联网，不修改人物包，不创建预览授权。草稿预览的 `--preview` 只表示使用已经取得的历史公共人物本地只读授权。

```powershell
python 直接对话/scripts/persona.py list
python 直接对话/scripts/persona.py doctor kongzi --preview
python 直接对话/scripts/persona.py search 孔子 学习 --preview --top-k 3
python 直接对话/scripts/persona.py search richard-feynman experiment --preview --kind evidence
python 直接对话/scripts/persona.py context zhuangzi --preview --max-chars 100000
```

`doctor` 检查准入、所有 manifest 声明文件及 JSON/JSONL 语法。更严格的 Schema、向量、索引和 checksum 检查由 `python tools/validate_repository.py` 执行。

检索从证据与情境记忆 JSONL 重建中文双字词/英文词 BM25 排序，不依赖数据库或 NumPy，也不称作语义嵌入。它不翻译查询或对齐跨语言语义；英文词不会自动匹配只有中文的材料。结果带人物 ID、记忆 ID、审核状态、来源和定位；撤回条目、本地专用条目及涉及非公开来源的条目不进入结果。候选情境记忆保留 candidate 标记，不伪装为已审核事实。可以直接查询 `E-0001` 或来源 ID；无词汇匹配时返回空结果。

默认编译器完整保留人物规范、功能契约和适配层，适配层始终最后加载。默认四个人物的证据和情境记忆都整体读入；容量不足时只省略完整的记忆文件，并在返回值中列出遗漏与 `requires_search_tool=true`。程序不得把这个结果交给缺少记忆检索工具的模型而假装材料已完整载入。规则本身超限时直接报错。`max_chars` 是字符数预算，不是模型 token 数或上下文长度保证。

模型质量、人物辨识度和来源权利仍按原有人工流程验收。

## 本机 Ollama 对话

在自己安装并启动的 Ollama 中选择已经下载的本地模型。程序不会安装模型、读取 API 密钥或使用云端模型；先查询模型元数据，拒绝声明 remote_host/remote_model 的模型。协议依据 [Ollama Chat API](https://docs.ollama.com/api/chat)、[工具调用协议](https://docs.ollama.com/capabilities/tool-calling) 和 [官方类型定义](https://github.com/ollama/ollama/blob/main/api/types.go)。

```powershell
python 直接对话/scripts/persona.py chat 孔子 --preview --provider ollama --model <已安装的本地模型>
python 直接对话/scripts/persona.py chat kongzi --preview --provider ollama --model <已安装的本地模型> --prompt "怎样把学到的东西用于判断？"
```

仅接收 HTTP 回环地址（默认 `http://127.0.0.1:11434`），禁用代理与重定向。启动栏明确显示材料和会话内容发送到的本机服务。关闭网络搜索，模型自身和本机服务的安装与配置由使用者管理；未知或不可信服务不应被当作隐私保障。

会话命令：

- `/research on|off`：切换自然回答与依据解释。
- `/sources [问题]`：显示上一轮真实工具调用的 ID，以及单独标记的事后记忆审计。
- `/counterevidence [问题]`：检查匹配记忆的限制/张力，不自动声称它们已构成反证。
- `/save 摘要`：显示用户填写的摘要，输入 `y` 后只保存该摘要至被忽略的会话目录。
- `/new`：清空当前会话上下文，保留人物和研究模式。
- `/help`、`/exit`：帮助与退出。

恢复摘要：在相同人物、相同人物包版本下追加 `--resume chat-<保存时返回的32位ID>`。不恢复完整聊天记录，不接受其他人物/版本的摘要，不把摘要当作历史证据。

模型支持工具调用时，可以自主使用 `search_memory`；正常回答没有强制 top-k。每轮最多四次工具调用，网络请求超时最多 60 秒，错误回合不会污染会话。若编译器省略了记忆，模型必须支持工具；不支持时明确失败。`--num-ctx`（默认 32768）和 `--max-chars` 应按实际模型容量配置，字符预算不能保证 tokenizer 或 Ollama 不截断输入；更严格的真实模型容量和质量验收仍待完成。

默认不持久化会话，不自动更新人物文件。当前回归使用离线桩与回环 HTTP 桩，验证工程行为，尚未运行真实人物质量实验。

## 私人 v2 包

本文 `persona.py` 与快捷入口仍处理旧版历史人物包。六类人物的外部本地 v2 包改用独立的[私人本地预览](私人本地预览.md)，不使用本页的 context、search 或保存/恢复命令。

## 精简候选比较（M2）

仅对现有四个历史公共人物，可在 `context` 或 `chat` 显式加 `--prompt-profile m2-v1`；不加时为 `current`，快捷入口不受影响。候选尚未通过真实质量评测，细节见[审计说明](../../docs/11-M2规则审计与精简候选.md)。

```powershell
python 直接对话/scripts/persona.py context kongzi --preview --prompt-profile m2-v1
python 直接对话/scripts/persona.py chat kongzi --preview --provider ollama --model <已安装的本地模型> --prompt-profile m2-v1
```

候选替换共用契约、人物规范和单人适配文字，保留原证据与情境记忆，沿用准入、权利过滤和整文件容量控制。候选文件缺失时失败，不悄悄退回原版。不同 prompt_profile 的摘要不能互相恢复；旧摘要只属于 current。严格实验仍需新会话，不能复用摘要。

`context_sha256` 是编译结果 UTF-8 的哈希，`input_sha256` 是实际纳入的各文件包装块（含路径标签与规范化换行）的哈希，不是磁盘原始字节哈希；遗漏文件不列入。它们用于核对实验输入，不证明推理时未被模型截断，也不证明质量。当前研究提示每轮仍由运行器追加，完整实验还须记录请求配置和消息。

## 可复现采样与实验元数据

`chat` 支持显式 `--temperature 0.7 --seed 20261008`。未提供时不向服务发送这两个字段，保持原默认行为；参数被校验为有限温度 0—2、整数种子 0—2147483647。本项目选定的范围属于客户端约束。固定种子不能保证跨硬件/版本逐字相同，也不能证明服务遵守参数。

底层 `OllamaProvider.inspect_identity()` 重新查询 `/api/show` 与 `/api/tags`，返回匹配模型名、digest、规范化元数据哈希、工具能力和显式 options；缺失/模糊 digest 或远端模型失败。它只读本机元数据，不下载模型、不返回模型模板正文。元数据哈希不等同权重哈希，digest 也只是本机服务报告的身份；实验应在请求前后比较并记录变化。

`last_metrics` 只保留最后一次成功请求的白名单计数、耗时及停止原因，不保留隐藏思考或回答正文。请求开始即清空旧指标；缺失字段留空，不能伪造 token 数。`done_reason=length` 要在评测中标记输出受限；prompt_eval_count 不能单独证明输入未截断。

实现依据：[Chat API](https://docs.ollama.com/api/chat)、[模型列表](https://docs.ollama.com/api/tags)、[参数定义](https://docs.ollama.com/modelfile)。目前只通过 HTTP 桩验证，真实实验配置与结果尚未冻结或生成。

## 四组开发试点输入

`python 直接对话/scripts/pilot_inputs.py --preview` 只读准备四人 × A/B/C/D 共 16 份上下文及两道共同开发题（32 次首轮请求预算、最多 64 次）。命令只输出摘要、哈希和待定模型状态，不调用模型、不保存回答。程序接口返回消息用于后续运行器；当前没有执行入口。

A 为通用助手，B 为简短人设，C 从 M0 冻结提交恢复原加载文件并核对哈希，D 使用当前 m2-v1。四组统一禁网、禁写、无工具；要求完整且仍符合当前权利过滤的记忆，不能用旧 Git 版本复活撤回材料。任何人物事实材料变化都需重新审查比较基线。历史指令作为比较材料读取，不执行旧代码。需完整 Git 历史；浅克隆或缺失历史对象会明确失败。

C 保留历史包文本与顺序，四组另加相同运行边界；这是控制条件下的比较输入，不冒充原历史运行器逐字请求。公开开发题不是盲评题，默认不加载评测页或评分预期。输入哈希包含实际 system 消息，模型身份仍为 null；真实容量、模型版本、运行预算/中止/恢复、人工盲评待后续节点。禁止把 MODEL_PENDING 当作已完成真实实验。
