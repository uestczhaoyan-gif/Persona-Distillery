# 本地检查、检索和上下文编译

需要 Python 3.10+，这些命令仅使用标准库，不联网，不修改人物包，不创建预览授权。草稿预览的 `--preview` 只表示使用已经取得的历史公共人物本地只读授权。

```powershell
python 直接对话/scripts/persona.py list
python 直接对话/scripts/persona.py doctor kongzi --preview
python 直接对话/scripts/persona.py search 孔子 学习 --preview --top-k 3
python 直接对话/scripts/persona.py search richard-feynman experiment --preview --kind evidence
python 直接对话/scripts/persona.py context zhuangzi --preview --max-chars 100000
```

`doctor` 检查准入、所有 manifest 声明文件及 JSON/JSONL 语法。更严格的 Schema、向量、索引和 checksum 检查由 `python tools/validate_repository.py` 执行。

检索从证据与情境记忆 JSONL 重建中文双字词/英文词 BM25 排序，不依赖数据库或 NumPy，也不称作语义嵌入。结果带人物 ID、记忆 ID、审核状态、来源和定位；撤回条目、本地专用条目及涉及非公开来源的条目不进入结果。候选情境记忆保留 candidate 标记，不伪装为已审核事实。可以直接查询 `E-0001` 或来源 ID；无词汇匹配时返回空结果。

编译器完整保留人物规范、功能契约和适配层，适配层始终最后加载。默认四个人物的证据和情境记忆都整体读入；容量不足时只省略完整的记忆文件，并在返回值中列出遗漏与 `requires_search_tool=true`。程序不得把这个结果交给缺少记忆检索工具的模型而假装材料已完整载入。规则本身超限时直接报错。`max_chars` 是字符数预算，不是模型 token 数或上下文长度保证。

模型质量、人物辨识度和来源权利仍按原有人工流程验收。

## 本机 Ollama 对话

在自己安装并启动的 Ollama 中选择已经下载的本地模型。程序不会安装模型、读取 API 密钥或使用云端模型；先查询模型元数据，拒绝声明 remote_host/remote_model 的模型。协议依据 [Ollama Chat API](https://docs.ollama.com/api/chat)、[工具调用协议](https://docs.ollama.com/capabilities/tool-calling) 和 [官方类型定义](https://github.com/ollama/ollama/blob/main/api/types.go)。

```powershell
python 直接对话/scripts/persona.py chat 孔子 --preview --provider ollama --model <已安装的本地模型>
python 直接对话/scripts/persona.py chat kongzi --preview --provider ollama --model <已安装的本地模型> --prompt "怎样把学到的东西用于判断？"
```

仅接收 HTTP 回环地址（默认 `http://127.0.0.1:11434`），禁用代理与重定向。启动栏明确显示材料和会话内容发送到的本机服务。关闭网络搜索，模型自身和本机服务的安装与配置由使用者管理；未知或不可信服务不应被当作隐私保障。

会话命令：

- `/research on|off`：切换自然回答与依据解释。
- `/sources [问题]`：显示上一轮真实工具调用的 ID，以及单独标记的事后记忆审计。
- `/counterevidence [问题]`：检查匹配记忆的限制/张力，不自动声称它们已构成反证。
- `/save 摘要`：显示用户填写的摘要，输入 `y` 后只保存该摘要至被忽略的会话目录。
- `/new`：清空当前会话上下文，保留人物和研究模式。
- `/help`、`/exit`：帮助与退出。

恢复摘要：在相同人物、相同人物包版本下追加 `--resume chat-<保存时返回的32位ID>`。不恢复完整聊天记录，不接受其他人物/版本的摘要，不把摘要当作历史证据。

模型支持工具调用时，可以自主使用 `search_memory`；正常回答没有强制 top-k。每轮最多四次工具调用，网络请求超时最多 60 秒，错误回合不会污染会话。若编译器省略了记忆，模型必须支持工具；不支持时明确失败。`--num-ctx`（默认 32768）和 `--max-chars` 应按实际模型容量配置，字符预算不能保证 tokenizer 或 Ollama 不截断输入；更严格的真实模型容量和质量验收仍待完成。

默认不持久化会话，不自动更新人物文件。当前回归使用离线桩与回环 HTTP 桩，验证工程行为，尚未运行真实人物质量实验。
